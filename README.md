# 賽棋 / Quad6 — playable browser prototype

2人用のドミノ戦略ゲーム「賽棋（Quad6）」の**実際に遊べる試遊版**。ダブルシックス・ドミノ2セット（計56枚）を使い、平場で天九式の役を競り、付札ではドミノの接続を行います。

**対応**: CPU戦（簡易AI）、同一端末での2人対戦（手札の受け渡し画面あり）、9枚配牌、平場・上書き・武牌9種・至尊・通常/最終付札・パス・公開除外・補充・交換・山枯らし・得点計算。

## 開発・起動

このリポジトリには、CSS・ルールエンジン・UIを1ファイルに組み込んだ **依存なしのブラウザ版** を配置しています。

`site/index.html` をブラウザで直接開くだけで遊べます。ローカルサーバーで確認する場合：

```sh
python3 -m http.server 4173 --directory site
# http://localhost:4173/
```

分割されたエンジン・UI・テストを含む開発用アーカイブは、別途配布版に含まれています。GitHub 上の公開用ファイルは単体HTMLです。

## GitHub Pagesへのデプロイ

`master` に push すると `.github/workflows/pages.yml` が `site/` を自動公開します。

**初回のみ** リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。以後のコミットは自動で再デプロイします。

## ルールの実装上の暫定裁定

会話で未確定だった箇所は試遊できるよう以下に固定しています。正式なVer.0.4で変更可能です。

- **平場の起点**: 役の2枚を並べ、2枚の外側に見える数字を左端・右端とします。中央の境界（✦）は、同じ数字が隣接しなくてもよい「天九の平場」です。出す際は各牌を反転できます。以後は左右端へ通常のドミノ接続。
- **上書き**: 現在の平場の役より強い役のみを出せます。雑同士の上書きは不可。同順位の文牌/武牌も上書き不可。
- **文牌の特例**: `[0|0]` 対子は `[6|6]` 対子だけに勝ち、その他の文牌より弱い。
- **付札の先手**: 平場で上書きを見送った人が最初の付札をします。
- **至尊の特殊付札**: `[0|0]`と`[6|6]`の2枚を両端0・6に分割接続できます。**0はワイルドではありません**。通常の付札はピップ点のみ、役点は付けません。
- **本場**: 最終上書き者が上書き回数×3点をまとめて獲得（上書き終了時）。役点・ピップ点は上書きされても残ります。
- **手札1枚の救済**: 局間の調整後、新しい平場に入る直前に2枚を強制補充。山が空になった場合の山枯らし罰は免除。
- **最終出牌**: 山札が尽きたら現在の場で続行。場が空なら役出しから開始。パスした人は最終出牌から脱落。残った人は連続手番。早アガリは山枯らし罰に優先。
- **先攻**: 局ごとに交代。
- **手札交換**: 局間に1人1アクション。公開除外の牌は再使用しません。

## 注意

- **試遊用プロトタイプ**です。役点・本場単価などはVer.0.3の暫定値です。
- CPUは強いゲームAIではなく、合法手の選択・手札管理を行う簡易AIです。
- 対局はブラウザ内だけで完結します。オンライン対戦・サーバー保存はありません。
- 素材はすべてCSS・自作SVGで生成し、外部画像の著作権に依存しません。表示フォントはGoogle Fontsが読み込めない環境でもシステムフォントにフォールバックします。

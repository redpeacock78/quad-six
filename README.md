# 賽棋 / Quad6 — playable browser prototype

2人用のドミノ戦略ゲーム「賽棋（Quad6）」の**実際に遊べる試遊版**。ダブルシックス・ドミノ2セット（計56枚）を使い、平場で天九式の役を競り、付札ではドミノの接続を行います。

**対応**: 一局戦・東風戦・半荘戦の持ち点制、CPU戦（簡易AI）、同一端末での2人対戦（手札の受け渡し画面あり）、9枚配牌、平場・上書き・武牌9種・至尊・通常/最終付札・パス・公開除外・補充・交換・山枯らし・得点計算。

## 遊ぶ

公開URL: https://redpeacock78.github.io/quad-six/

- CPU対戦：簡易AIと対戦。
- 同一端末2人対戦：手札の受け渡し画面つき。
- **相手の手牌枚数**：卓の向こう側に、CPUまたは相手の伏せ牌を枚数分表示。牌の表面は非公開。
- **終局時の盤面確認**：精算結果の「終局時の盤面を見る」で、場に残った牌・開放端・残り手札を見返し、得点画面に戻れます。
- ルールは画面内の「遊び方」から確認可能。

### 対局形式（Ver 0.4 試遊ルール）

| 形式 | ゲーム数 | ゲームごとの先手 |
| --- | ---: | --- |
| 一局戦 | 1 | プレイヤー1 |
| 東風戦 | 4 | 交代 |
| 半荘戦 | 8 | 交代 |

**持ち点は双方250点開始**。各ゲームはこれまでの56枚ドミノによる1ゲームを指します（ゲーム内部の平場・付札の複数ラウンドとは別です）。

ゲーム終了後は、**自分のゲーム得点 − 相手のゲーム得点**を自分の持ち点に加算し、相手から同じだけ差し引きます。たとえば119対84なら、250対250 → **285対215**。持ち点の合計500点は変化しません。

各ゲーム後に牌と山を混ぜ直して再配布し、ゲーム全体の先手は交代。規定の1/4/8ゲーム終了時の持ち点が高い側が勝ちです。現段階では**飛び終了なし**（持ち点がマイナスでも継続）。終了後はゲームごとの点差と最終持ち点を表示します。

## 開発・起動

このリポジトリには、依存パッケージ不要の **ES Modules版** と、CSS・ロジック・UIを埋め込んだ **オフライン用単体HTML版** の両方を配置しています。

`site/standalone.html` はブラウザで直接開けます。`site/index.html`（モジュール版）のローカル確認にはサーバーを起動してください。

```sh
python3 -m http.server 4173 --directory site
# http://localhost:4173/
```

ルールエンジン・対局管理・UIは `site/engine.js`・`site/match.js`・`site/ui.js` に分割しています。テストと単体版ビルドは以下のコマンドで実行できます。

```sh
npm test
npm run build:standalone
```

## GitHub Pagesへのデプロイ

`master` に push すると `.github/workflows/pages.yml` が `site/` を自動公開します。

**初回のみ** リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。以後のコミットは自動で再デプロイします。

## ルールの実装上の暫定裁定

会話で未確定だった箇所は試遊できるよう以下に固定しています。正式ルールで変更可能です。

- **平場の起点**: 役の2枚を並べ、2枚の外側に見える数字を左端・右端とします。中央の境界（✦）は、同じ数字が隣接しなくてもよい「天九の平場」です。出す際は各牌を反転できます。以後は左右端へ通常のドミノ接続。
- **上書き**: 現在の平場の役より強い役のみを出せます。雑同士の上書きは不可。同順位の文牌/武牌も上書き不可。
- **文牌の特例**: `[0|0]` 対子は `[6|6]` 対子だけに勝ち、その他の文牌より弱い。
- **付札の先手**: 平場で上書きを見送った人が最初の付札をします。
- **至尊の特殊付札**: `[0|0]`と`[6|6]`の2枚を両端0・6に分割接続できます。**0はワイルドではありません**。通常の付札はピップ点のみ、役点は付けません。
- **本場**: 最終上書き者が上書き回数×3点をまとめて獲得（上書き終了時）。役点・ピップ点は上書きされても残ります。
- **手札1枚の救済**: 局間の調整後、新しい平場に入る直前に2枚を強制補充。山が空になった場合の山枯らし罰は免除。
- **最終出牌**: 山札が尽きたら現在の場で続行。場が空なら役出しから開始。パスした人は最終出牌から脱落。残った人は連続手番。早アガリは山枯らし罰に優先。
- **先攻**: 局ごとに交代。
- **手札交換**: 局間に1人1アクション。公開除外の牌は再使用しません。

## 注意

- **試遊用プロトタイプ**です。役点・本場単価などはVer.0.3ベースの暫定値です。
- CPUは強いゲームAIではなく、合法手の選択・手札管理を行う簡易AIです。
- 対局はブラウザ内だけで完結します。オンライン対戦・サーバー保存はありません。
- 素材はすべてCSS・自作SVGで生成し、外部画像の著作権に依存しません。表示フォントはGoogle Fontsが読み込めない環境でもシステムフォントにフォールバックします。
